# 学生持续学习功能实施状态

功能 3 至 8 已完成并通过独立审查。Node.js 24.20.0 完整发布检查退出码为 0：68 个测试文件、759 项测试及额外 2 项 runtime 检查通过，构建和 lint 通过；结果为 `READY_WITH_LIMITATIONS`，0 个阻塞项、3 项运行边界。生产服务尚未部署。

| 功能 | 已实现行为 | 关键边界 |
| --- | --- | --- |
| 3. 学习档案 | 使用显式 24 类 section registry 导出；导入先校验和预览，再复制恢复为新的本机档案。 | 不覆盖当前档案；损坏、未知版本和跨档案记录会失败关闭；凭证不会导出。 |
| 4. 间隔复习 | 基于真实作答证据和当前内容版本安排 1、3、7 天复习。 | 这是产品节奏规则，不是学习效果保证；提示或错误后的成功不算独立掌握，同日重复不升级，内容版本变化不继承旧掌握。 |
| 5. 我的本领册 | 展示具体知识、代表题、日期、提示和错误证据；状态为练过、在巩固、已掌握。 | 已掌握要求同一内容版本完成首次独立作答和两次到期独立复习，不能只按次数计数。 |
| 6. 柔性周计划 | 学生自行选择学习日和任务量，可在中断后继续。 | 只用真实学习记录判断完成；没有扣分、补债或连续打卡压力。 |
| 7. 知识关联宠物故事 | 为当前课程证据提供复习、表达、发现三类小章节。 | 复习须在打开故事后产生新的真实复习证据；表达和发现可以自报完成，但不增加掌握证据或奖励。 |
| 8. 家庭档案与云同步 | 可建立新的本机孩子档案；家长账号可手动上传、下载完整学习快照。 | 云端使用 revision CAS；409 冲突保留双方记录，不自动覆盖、合并、恢复或重试。 |
| 年级拓展 | 已增加 9 节三年级原创短课。 | 它们不是完整教材册，也没有宣称教师或出版社校审。 |
