# 学生学习体验改进

日期：2026-09-08。开发分支：`feat/student-learning-experience`。

## 目标与原则

学生打开后知道学什么，遇到困难有具体帮助，离开后能够继续，并能看见自己学会了什么。软件验证只能证明流程和记录符合约定，实际学习效果仍需学生试用验证。

保留现有无惩罚重试、每日奖励上限。阅读完成、提示后完成与独立掌握分别表达，不因一次答对或点完页面推定长期掌握。允许结束和休息，不增加断签损失、宠物饥饿或随机付费奖励。

## 第一批：独立完成一次学习

本批已实现范围：

1. 以一年级北师大数学上册开学单元“我上学啦”的三课（倾听与整理、点数、几个和第几）为内容样板，校准学习目标与实际讲解、题目；修正课内指向不存在区域的提示。
2. 完成课程后在当前学习路径直接开始基础练习，减少跳入长详情页再次寻找入口。保留正式练习及扩展入口。
3. 给样板单元提供与题意有关的提示，支持修改答案再试。沿用已有进度、帮助使用和奖励记录。
4. 修复 Windows 下发布检查无法启动 npm 和 TTS 缓存断言的既有失败，恢复可信的完整验证。
5. 数学课后练习提供中文“听题”和已展开的“听提示”，由学生主动播放，切换内容或退出即停止；不支持朗读时保留文字和答题操作。语文和英语练习的语言适配留待后续扩展。

验收：真实课程完成后能进入练习并返回；无练习内容时有明确退出；切换课程或学生不串数据；重试不重复奖励；样板课程目标和提示有回归测试；完整测试、构建、lint 和发布检查记录实际结果。

## 第二批：课程正文阅读辅助

已实现：在课程播放页为当前可见的语文、数学正文提供“听这一步”，配合标准、大字、特大字三档字号。各步骤可分别听读，不自动跨步骤播放，不读取练习答案或尚未展开的互动解答。静音、切换步骤和退出均沿用停止播放规则。

字号仅调整当前页面正文的显示，不改教材内容、完成状态或奖励。英语仍使用已有英语听读能力；本批不把英语内容交给中文语音。

课程完成后可以通过步骤按钮只读回看与重听，完成进度保持 100%。回看不重写学习会话、不重复发奖，也不重新启动正式测验。

验收通过：Node.js 24.20.0 下完整发布检查退出码 0，59 个测试文件、689 项测试及额外 2 项 runtime 检查通过；门禁为 `READY_WITH_LIMITATIONS`，0 个阻塞项、3 项既有边界。独立审查 APPROVE。Edge 在 320×700 和 390×844 下无横向溢出，键盘可切换字号，字号点击区域均为 44px；听读与完成后回看不改变进度，控制台无错误。真实首课没有 practice 步骤，完成态练习保护由自动化回归覆盖；未评估声音硬件、发音质量或真机手机。实现记录：`.codex/tasks/student-reading-20260908/`。

## 2026-10-15：附录查阅与启动体验

- 修复来源说明被过滤后，识字表、写字表和词语表因固定块序号而丢失结构化显示的问题。表格跟随保留下来的正文块，原教材数据和步骤编号保持不变。
- 字词表支持按课号筛选，或查找汉字、拼音、词语。拼音查询不要求输入声调，筛选无结果时可以一键恢复全部；不同语文园地在选择器中显示各自编号。筛选只改变当前显示，不保存为学习完成或掌握证据。
- 没有教材练习的栏目显示“回想与表达”；没有闯关的栏目显示“回看与复习”，学习路径按实际内容提供提示。
- 登录、找回密码不再预加载课程目录；入门页面和课程配置按路由加载。入口主脚本从上一轮构建的约 3.14 MB 减至约 61 KB（未压缩，仅比较入口主脚本，公共依赖另计）。进入学习页面时仍需加载完整课程目录，按年级进一步拆分仍是后续性能工作。
- 首次页面加载期间保留启动提示；首次路由加载失败时提供重新打开按钮，保留本机学习记录。

本轮使用隔离的本地测试数据库和生产构建验证，不影响现有账号数据库。浏览器已验证真实识字表的无声调拼音搜索和课号交叉筛选，320px、390px 下无横向溢出；启动等待、失败恢复及表格显示和筛选有自动回归覆盖。构建、类型检查和 lint 通过。全量测试结果与上一轮逐项对照，历史失败项单独记录，不以界面验证代替完整发布验收。

最终回归：1,888 项测试中 1,721 项通过，167 项失败；与上一轮 174 项失败逐项对照，没有新增失败，三年级和五年级字词附录的 7 项历史失败已修复。新增的 6 项启动恢复、附录渲染和筛选测试全部通过。课程目录仍有既有的大分块构建提示，完整发布验收尚未通过。
