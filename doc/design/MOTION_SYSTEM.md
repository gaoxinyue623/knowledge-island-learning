# 知识岛｜动效系统

> 本文档定义知识岛的角色、地图、节点、答题反馈、奖励、页面转场和加载动效。它是 PHASE 3 设计规格，不代表已有动画资源、动画库或前端实现。

## 1. 动效原则

1. 动效必须让学生理解“发生了什么”，不能只是增加刺激。
2. 学习内容、题干、输入和 CTA 优先于角色与装饰。
3. 反馈动效不阻塞继续按钮；不可跳过的长动画不进入学生端。
4. 错误使用思考与鼓励，不使用倒地、哭泣、失败结算或 `GAME_OVER`。
5. 不让所有按钮弹跳；按钮只在必要的 Press / Focus 状态提供微反馈。
6. 页面切换、地图移动和奖励动效在 Mobile / Tablet 控制并发数量。
7. Reduced Motion 关闭漂浮、循环装饰、大粒子和自动镜头，但保留状态、文字、图标和 Focus。

## 2. Motion Token

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `duration.fast` | 120～180ms | Hover、Focus、选中、展开小变化 |
| `duration.normal` | 200～350ms | 卡片进入、页面局部切换、Drawer |
| `duration.slow` | 350～500ms | 地图镜头、复杂内容展开 |
| `duration.reward` | 500～1000ms | 正确反馈、轻庆祝、节点解锁 |
| `duration.rewardMax` | 1000～2000ms | 通关奖励总展示上限，可提前跳过 |
| `ease.standard` | 平滑加减速 | 页面、卡片和普通状态 |
| `ease.bounce` | 低幅回弹 | 角色轻跳、按钮 Press；不用于所有按钮 |
| `ease.reward` | 柔和加速后回落 | 奖励、解锁和成长 |
| `stagger.short` | 40～80ms | 少量卡片逐项出现 |
| `stagger.maxItems` | 3～5 项 | 限制连续出现的元素数量 |

默认不使用持续循环动画；需要循环时必须有静态替代和 Reduced Motion 分支。

## 3. 角色 Motion

| 触发 | 角色状态 | 时间 / 频率 | 可跳过 | Reduced Motion |
| --- | --- | --- | --- | --- |
| 首屏等待 | `IDLE` | 轻微呼吸，低频 | 不适用 | 静态站姿 |
| 学生选择地区 / 年级 | `HAPPY` | 一次点头或挥手，≤500ms | 不适用 | 静态微笑 |
| 学习思考 | `THINK` | 轻摆一次，不循环 | 不适用 | 静态思考姿势 |
| 首次错误 | `THINK` → `ENCOURAGE` | 500～1000ms | 是 | `ENCOURAGE` 静态图 |
| 正确作答 | `SUCCESS` | 500～1000ms | 是 | `SUCCESS` 静态图 + 文案 |
| 复习提醒 | `SLEEPY` → `ENCOURAGE` | 一次短提示 | 是 | 静态复习图标 |
| 奖励结算 | `EXCITED` | 1～2 秒 | 是 | 静态奖励状态 |

角色动作不改变评分、教材、解锁和题目难度。

## 4. 地图 Motion

### 4.1 地图进入

- Desktop：地图场景在 `duration.normal` 内淡入，当前节点轻微定位。
- Tablet：保持触控位置，不自动持续平移；进入时最多一次短镜头定位。
- Mobile：将当前节点滚动到可读区域，避免自动长距离移动造成迷失。

### 4.2 节点状态

| 事件 | 动效 | 时间 | 说明 |
| --- | --- | ---: | --- |
| `locked` | `Lock` 静态 + 轻微压低透明度 | 无循环 | 显示解锁条件 |
| `available` | 低幅呼吸或光圈 | 1～2s 循环 | Reduced Motion 下静态边框 |
| `inProgress` | 角色停在节点附近 | 无自动动画 | 继续 CTA 常驻 |
| `completed` | `CheckCircle` 进入 | 300～500ms | 可短暂角色 `SUCCESS` |
| `perfect` | 原创皇冠或 `Star` 图标出现 | 500～1000ms | 不使用 Emoji |
| 解锁 | 路径高亮 + 节点出现 | 500～1000ms | 不阻塞下一步 |

地图主题名、节点动画和角色位置属于体验层，不能反向修改教材事实。

## 5. Question Feedback Motion

### 5.1 正确

1. 选项或输入区域出现明确成功边框和 `CheckCircle`。
2. 知识团子做一次小跳或点头。
3. 文案为“答对啦”“做得不错”或“你发现规律了”。
4. 动效 500～1000ms，可随时点击“下一题”。

### 5.2 错误

1. 题目保持原位，不震动整页、不清空作答。
2. 使用柔和边框变化与 `Lightbulb` / `RefreshCcw`。
3. 文案为“差一点，再试一次”。
4. 知识团子使用 `THINK` 或 `ENCOURAGE`。
5. 连续错误后进入提示、分步解析或重新学习，不进入失败结算动画。

### 5.3 Hint 展开

- `Hint1` 在 `duration.fast` 内展开方向提示。
- `Hint2` 显示关键步骤，保留学生继续作答的机会。
- `Hint3` 提供接近答案的教学提示，但答案仍由评分规则返回。
- 提示展开不自动滚动到页面顶部，不遮挡题目输入。

## 6. Reward Motion

| 阶段 | 动效 | 约时长 | 可跳过 |
| --- | --- | ---: | --- |
| 结果进入 | `RewardPanel` 上浮或淡入 | 200～350ms | 不适用 |
| XP / 星星 / 金币 | 数字递增或图标出现 | 500～1000ms | 是 |
| 装扮 / 节点解锁 | 局部高亮 | 500～1000ms | 是 |
| 奖励结束 | 指向下一步 CTA | ≤300ms | 是 |

奖励总时长不超过约 1～2 秒。奖励不能把继续按钮隐藏在动画后，也不能诱导学生重复使用以延长时长。

## 7. Page Transition

- 默认使用 `duration.normal` 的淡入 / 轻位移；不使用全屏旋转或长场景过渡。
- Onboarding 步骤切换保留已选内容，使用短暂横向方向感，但不能造成“迷路”。
- Question 切题保持 Shell 位置稳定，仅更新题干与交互区；避免整页闪烁。
- Modal / BottomSheet 使用 `duration.normal`，支持 Escape、关闭按钮和 Reduced Motion 静态出现。
- Mobile 页面转场不依赖复杂 3D，避免低性能设备卡顿。

## 8. Loading Motion

- 课程 / 教材解析：知识团子轻微 `THINK` + “正在准备你的课本”。
- 关卡加载：角色轻动作 + “正在准备关卡”。
- 题目加载：结构骨架 + 轻量状态，不连续闪烁。
- 网络重试：图标和文字反馈，按钮保持可点击。
- Reduced Motion：使用静态插画、骨架、文字和进度变化。

## 9. 性能边界

- 同一视图最多一个主要角色动效、一个状态反馈和少量装饰动效并行。
- Mobile / Tablet 禁止大面积持续粒子、自动镜头和多层透明滤镜。
- Offscreen 地图节点、角色和装饰暂停动画。
- 动效不可影响题目输入、键盘 Focus、滚动或提交。
- 正式动画资源必须使用 `MediaAsset` 记录版本、来源、版权和尺寸；资源加载失败时提供静态占位。

## 10. Reduced Motion 规则

当 `prefers-reduced-motion: reduce` 时：

- 关闭漂浮、呼吸循环、粒子、自动地图镜头和连续数字滚动。
- 将页面 / 卡片转场改为即时出现或短淡入。
- 将角色动作替换为静态姿态。
- 保留 `CheckCircle`、`Lock`、提示文案、Focus ring、选中边框和加载文字。
- 不删除必要的反馈信息；动效减少不能导致状态不可理解。

## 11. 动效验收

1. 动效有明确触发条件、时间、是否可跳过和静态替代。
2. 正确、错误、提示、解锁、奖励和加载均不阻塞学习主动作。
3. 不出现全屏渐变、过度 3D、持续高刺激、所有按钮弹跳或失败惩罚。
4. Reduced Motion、低性能设备和离线状态仍能理解流程。
5. 角色与动画资产可通过 `MediaAsset` 追踪来源、版权和版本。
