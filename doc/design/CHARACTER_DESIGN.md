## 1. 角色定位

“知识团子”是知识岛的原创陪伴角色，不是战斗角色，也不替代教师。它的职责是：

- 在首次配置时带学生进入知识岛。
- 在首页帮助学生理解“今天学什么、下一步是什么”。
- 在地图上标记当前学习位置和前进方向。
- 在答题时表达鼓励、思考和轻量庆祝。
- 在奖励与复习时提供陪伴感，不制造焦虑或失败羞耻。

角色应让学生感到“我正在和一个小伙伴一起学习”，而不是被排行榜或失败惩罚驱动。

## 2. 原创边界

### 2.1 必须保持的原创特征

- 圆形或略带不对称的软弹身体轮廓。
- 短手短脚，动作幅度小而清晰。
- 大眼睛，但眼型、瞳孔和高光组合需建立自有规范。
- 简单、可识别的脸部结构，不使用现有商业角色的五官模板。
- 轻果冻或玩具触感，使用本产品的颜色 Token，不模拟具体商业 IP 材质。
- 头顶或身体上的可替换小装饰，用于角色成长和个性化。

### 2.2 明确禁止

不得复制或高度模仿蛋仔派对、宝可梦、迪士尼、任天堂、马里奥、商业教育 App 或其他商业 IP 的外形、动作、服装、地图和叙事关系。正式资产未生成前，不使用上述素材“临时看效果”。

## 3. 轮廓与比例

### 3.1 基础比例

| 部位 | 设计建议 |
| --- | --- |
| 身体 | 近圆形，宽高约 1:1；允许轻微不对称以保留手作感 |
| 头部 / 身体 | 不另画写实头身分割；脸部位于身体上半部约 40% 区域 |
| 手臂 | 身体宽度的约 20%～25%，清晰但不尖锐 |
| 腿脚 | 短而稳定，约占整体高度 15%～20% |
| 眼睛 | 两只主眼间距保持一致；低年级可略放大，高年级减少夸张度 |
| 装饰 | 单次视图最多一个主视觉焦点，避免装扮遮挡脸部和动作 |

这些是绘制起点，不是实现硬编码值。不同尺寸下优先保证轮廓识别和表情可读。

### 3.2 视觉材质

- 使用柔和纯色、局部高光和低透明阴影表达轻 3D。
- 不使用高光闪烁、金属拟真、厚重纹理或连续粒子。
- 小尺寸头像保留身体、眼睛和主装饰三部分；复杂服装在 Mobile 头像中隐藏细节。

## 4. 面部与情绪

### 4.1 表情原则

表情改变眼睛、眉线、嘴形和身体姿态，不使用夸张哭泣、倒地或爆炸式反馈。错误时表达“我来陪你再想想”，不是“你失败了”。

### 4.2 情绪状态枚举

| 状态 | 视觉表现 | 使用场景 | 禁止表达 |
| --- | --- | --- | --- |
| `IDLE` | 轻微呼吸、眨眼 | 首页、等待 | 持续大幅运动 |
| `WALK` | 小步移动、身体轻摆 | 地图移动 | 快速穿越遮挡内容 |
| `RUN` | 短时间加速、手臂展开 | 节点切换 | 长时间循环 |
| `JUMP` | 小幅离地、落地回弹 | 解锁、轻庆祝 | 震屏式跳跃 |
| `THINK` | 眼睛偏移、手托下巴 | 学习思考、第一次错误 | 夸张困惑到无法继续 |
| `HAPPY` | 微笑、身体打开 | 普通完成 | 盖住学习结果 |
| `EXCITED` | 两次以内小跳或挥手 | 挑战成功、奖励 | 长时间高刺激 |
| `ENCOURAGE` | 向前伸手、点头 | 错误、复习提醒 | 指责、摇头否定 |
| `CONFUSED` | 轻微歪头、问号形原创符号 | 需要重新理解 | 愁眉苦脸或羞辱 |
| `SUCCESS` | 小跳、亮色边缘短暂出现 | 正确、通关 | 与失败状态混用 |
| `TRY_AGAIN` | 深呼吸、重新指向题目 | 作答错误后 | `GAME_OVER`、倒地 |
| `SLEEPY` | 眨眼变慢、坐姿 | 空闲或复习提示 | 用于惩罚学生 |

明确不提供 `FAIL_DEFEATED`、`GAME_OVER`、`CRYING_FAILURE` 等过强失败状态。

## 5. 动作与情绪映射

动作必须服务于界面状态，且可在 Reduced Motion 下退化为静态姿态：

| 触发事件 | 默认状态 | 动作上限 | 继续学习是否被阻塞 |
| --- | --- | --- | --- |
| 页面加载 | `IDLE` / `THINK` | 一次短动作 | 否 |
| 用户选择地区或年级 | `HAPPY` | 轻点头或挥手 | 否 |
| 正确作答 | `SUCCESS` | 500～1000ms | 否 |
| 错误作答 | `THINK` → `ENCOURAGE` | 500～1000ms | 否 |
| 需要复习 | `SLEEPY` → `ENCOURAGE` | 一次提示动作 | 否 |
| 地图解锁 | `RUN` → `JUMP` | 1 秒内 | 否 |
| 关卡奖励 | `EXCITED` | 1～2 秒，可跳过 | 否 |

“动画完成后才能点击下一步”不是默认行为。所有关键 CTA 在反馈动画期间仍应可操作，或提供明确的跳过动作。

## 6. 装扮槽位

`CharacterAvatar` 的装扮槽位：

```text
body
face
hat
clothes
backpack
shoes
accessory
effect
themeSkin
```

装扮只改变视觉：

- 不提高正确率。
- 不降低题目难度。
- 不跳过课程内容。
- 不改变答案或评分。
- 不改变解锁条件和公平性。

装扮名称、图像、来源、版权和版本由资产数据维护；页面不能用文字猜测资产属于哪一套教材或地区。

## 7. 角色在产品流程中的使用

| 场景 | 角色职责 | 信息优先级 |
| --- | --- | --- |
| `WelcomeOnboarding` | 欢迎、指引开始 | 主文案和 CTA 高于角色 |
| `RegionSelect` | 陪伴选择地区 | 不遮挡搜索和列表 |
| `GradeSelect` | 鼓励选择年级 | 不暗示未开放年级可进入 |
| `TextbookConfirm` | 帮助核对三科课本 | 不替 UI 推断出版社 |
| `CharacterSetup` | 让学生选择/命名外观 | 不影响课程配置 |
| `Home` | 显示当前任务或学习位置 | “继续学习”高于角色动画 |
| `LearningMap` | 站在当前节点附近 | 指示当前位置，不代替节点状态 |
| `Lesson` / `Question` | 表达思考、鼓励和正确 | 不遮挡题干和答案 |
| `Result` | 庆祝完成、指向下一步 | 奖励不锁住 CTA |
| `WrongBook` / 复习 | 陪伴重新挑战 | 不显示羞辱性语气 |

## 8. 地图与课程状态

角色位置是学习体验投影，不是课程事实：

- `locked`：角色可在节点外观察，配合 `Lock` 和“完成上一关后解锁”。
- `available`：角色面向节点，动作保持低频。
- `inProgress`：角色停在当前节点附近，显示继续入口。
- `completed`：角色朝向下一节点，可短暂 `SUCCESS`。
- `perfect`：角色可使用一次原创皇冠或 `Star` 图标，但不能使用 Emoji。

教材单元、知识点、题目和审核状态不能从角色动作反推；角色只读页面已经解析出的状态。

## 9. 年龄视觉适配

| `ageVisualLevel` | 年级 | 角色表现 |
| --- | --- | --- |
| `LOWER_PRIMARY` | 1～2 年级 | 轮廓更大、表情更清楚、动作更慢、文字更少 |
| `MIDDLE_PRIMARY` | 3～4 年级 | 图形与文字平衡，增加探索和闯关反馈 |
| `UPPER_PRIMARY` | 5～6 年级 | 减少幼儿化装饰，增加装备细节和探索姿态 |

角色核心轮廓、状态枚举和装扮公平性不随年龄改变；只调整尺寸、信息密度和装饰复杂度。

## 10. 资源与版本规则

正式角色资源进入 `MediaAsset` 后至少记录：

- `mediaType`：通常为 `SVG`、`ANIMATION` 或 `IMAGE`。
- `storageKey`、`url`、`mimeType`、尺寸和版本。
- `altText`（装饰性资源也要有语义策略）。
- `sourceId`、`copyrightStatus`、`license`、`status`。

角色组件只引用 `mediaAssetId`，不保存或拼接真实 URI。替换角色资源必须创建新版本，不能覆盖已经被学习记录引用的历史显示。

## 11. 角色设计验收

1. 学生能在小尺寸下识别知识团子，但不会把角色误认为已有商业 IP。
2. 错误反馈至少使用 `THINK`、`ENCOURAGE` 或 `TRY_AGAIN`，不使用失败羞辱状态。
3. 角色动画不遮挡题目、按钮或地图当前位置。
4. Reduced Motion 下仍能通过静态角色、图标和文案理解状态。
5. 装扮只影响外观，不影响学习公平。
6. 正式角色资产具备 `MediaAsset` 来源、版权和版本追踪。
