# 动手练习与路线动画

2026-09-06，面向项目维护者的实现与验证说明。本次在原有题目之外增加数学、语文和英语动手练习，并更新思维路线的角色表现；没有替换原题、改变闯关身份或重置已有通过记录。

语文与英语详情提供「新玩法」跳转；课外故事导航增加「动手练习」，不用先通过旧闯关才能进入。数学保留原有「看看怎样凑十」演示和计算题，独立实验室不占用旧关卡序号。

## 输入与所有权

- `QuestTraining.vue` 使用原有、已通过访问条件的 `ReadingQuest` 和当前学习文本，决定是否显示附加练习；不改基础／强化投影，不改变内容版本校验。
- `TenFrameWorkshop.vue` 只读基础题的 `ten-bridge` 加法数据。输入为两个 1–9 的整数且和不小于 10；小棒身份唯一，固定小棒不移动，已有小棒的格子不能重复接收。
- `evidencePractice.ts` 是证据练习的只读投影：教材复用已有题目种子，先按标题、适用教材及真实文本匹配；课外故事复用现有问题、答案和事件序列。只剔除展示标题与课后题／教学提示等附加部分，不把这些提示当成原文证据，不写回课程正文。
- 原文句子保留标点，匹配时忽略空白与标点。证据跨句时需选出对应句子集合；漏选、额外无关句都不通过。本版使用每题预设的直接证据，尚不自动理解其他可能合理的论证；匹配失败不显示该练习。
- 教材排序是「在当前原文中的先后顺序」，不是宣称唯一因果解释。课外故事排序沿用该故事的事件序列。理由是开放表达，只提供支架、提示与自查，不做关键词评分。
- `ListenPlaceWorkshop.vue` 拥有新增的三个原创英语位置场景，图形由 `WorkshopObject.vue` 绘制。朗读默认复用 `useEnglishReadAloud` 的设备英语声音；2026-09-07 增加按需选择豆包合成，见 [豆包语音说明](../operations/DOUBAO_TTS.md)。不是教材原声，不添加录音或语音识别。
- `ThinkingPathBoard.vue` 只消费 `ThinkingPlayer` 的合法行走方案，复用现有团子形象；验证和完成进度仍由原来的 thinking validator／store 管理。

本次没有修改 MASTERY_V1、STRATEGY_V1、地图解锁、生产来源 guard 或任何教材的审核状态。

## 操作、回退与状态

小棒和英语物品支持指针拖放，也支持「先点物品，再点位置」及原生按钮的 Tab／回车／空格操作。`usePieceTransfer` 对拖放根节点做范围检查；拖到练习外不改变摆放，取消指针和卸载会清理监听器。拖动不要求儿童精确操作，点选是等价入口。

英语默认不展示指令文字，文字帮助可主动展开。未找到英语声音、不支持朗读、静音或播放失败时仍可由家人读指令或看文字练习，不把这一过程记作独立听懂。播放只由用户发起，切换场景、教材、档案、静音或离开页面时停止，未进行发音质量评价。

路线移动动画约 280ms；在 300ms 单步完成前暂不接受下一步、撤回或提交，避免连续转弯时跨格斜穿。开启系统或应用「减少动画」时即刻更新位置，不等待动画；清空、换任务／档案和卸载清理计时器。障碍格不可进入，终点和补给条件仍由原来的验证器判定，不是碰到旗子就自动完成。

**新增实验室的摆放、标记、排序与口头自查只在本次页面内存中保留。** 刷新、离开、切教材或档案后重新练习，页面有说明。不写新增存储键，也不写 QuestionAttempt、LearningEvidence、History、WrongBook、ReviewQueue、Mastery、奖励或教材进度。原来基础／强化／课外阅读闯关与思维完成记录继续使用原有本地存储；完成动手实验不会自动完成原题。
