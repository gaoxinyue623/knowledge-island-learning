# 课后强化训练

2026-09-06 体验优化后：首次进入知识点详情页默认使用「基础热身」，可自主切换「强化训练」。已选择的强度、组号与通过关卡会按学习档案保存在本机。本说明面向内容和前端维护者，不代表教材审核结论。

新增的独立小棒实验室、原文证据／排序说理和英语听指令摆物见 [动手练习说明](HANDS_ON_PRACTICE.md)。它们保留本页所述的原题与进度，不增加旧关卡序号；覆盖条件和仅在内存保留的状态单独说明。

## 学生体验

每组 9 关，依次为独立热身、方法进阶、综合实战，各 3 关。答对才开放下一关；答错可修改，提示分两步展开，不直接跳关。小结区分首次独立通过、重试和使用提示，允许重练错过的关卡。

「换一组强化题」在三组固定变式间循环；每组分别保存，回到旧组可继续。主动重练会重新开始当前轮，进行中需确认，不清除累计通过足迹。不是无限随机出题，也不是按掌握度自适应生成。变式会改变部分数值、词汇、线索或情境条件；同一课的核心方法题可能重复，不把 27 个题目实例宣称为 27 道完全不同的题。

| 学科 | 强化内容                                                                                                                     |
| ---- | ---------------------------------------------------------------------------------------------------------------------------- |
| 数学 | 独立计算、反向填数、结果配对、方法与错因辨析、数字和符号搭算式、连续情境题；按课程类型提供测量、数表、图形分类或图形运动任务 |
| 语文 | 文意与原文依据、句意联结、含干扰字的补句、句段排序、推理与迁移、交流方法多选                                                 |
| 英语 | 含干扰字母的拼写、词义配对、拼写纠错、不给完整英文示例的组句、表达句型与词汇应用                                             |

语文有 12 个按题名和原文证据匹配的推理、迁移种子；其余课文使用通用阅读方法与当前文本练习，不宣称每课已有独立编写的深度阅读题。开放表达仍不自动判分，英语不评价口语发音。

## 数据与状态边界

- 入口是 [QuestTraining](../../src/components/knowledge-point/QuestTraining.vue)；[trainingQuest](../../src/services/content-expansion/trainingQuest.ts) 先取得原有、已通过访问条件的基础闯关投影，再调用数学或语言构造器。
- 内容仍属于 `content-expansion`；使用当前教材、课程、知识点和可读内容，不新增教材事实或地区选择限制。
- 训练 ID 包含基础练习 ID、`training-v1` 和组号。题目与活动继承来源和 SAMPLE 标识，保留现有生产访问限制，不将生成成功视为审核完成。
- 封闭题复用现有确定性答案校验；匹配和排序复用已有活动组件。没有修改 QuestionEngine、MASTERY_V1、STRATEGY_V1 或地图解锁算法。
- `questProgressStorage` 使用 `schemaVersion: 1`。`knowledge-island.quest.v1:` 按档案、练习身份保存通过关卡、当前关卡、提示／错误记录、错关重练轮和小结状态；不保存题目正文、答案或未提交草稿。`knowledge-island.quest-choice.v1:` 单独记录基础／强化选择和组号。只在本机保存，没有跨设备同步。
- 加载时进行 Zod、档案／练习身份和连续通关校验。题目或来源变化使旧通过记录失效；旧版无存储时从第一关开始。损坏或未来版本的存储保持原样，本次只在内存练习；保存失败显示提示，不谎称已保存。
- 组件缓存身份包括 profileId 和练习 ID。教材及档案之间不复用作答状态。
- 不写 QuestionAttempt、LearningEvidence、History、WrongBook、Review Queue、奖励或教材学习进度。本页的「重练错过的关卡」不是正式错题本记录。
- 缺少可用文本或不支持强化训练时回退到基础练习；基础练习也不可用时仍由原有详情页处理。没有为了展示新训练而放开来源限制。

## 覆盖与验证

候选内容回归目前覆盖 11 本教材中已有基础闯关的 348 个节点：数学 124、语文 186、英语 38。每个节点检查三组、每组九关，共 9,396 个关卡实例。这不是整个 Curriculum 数据集的节点总数，也不代表这些内容在所有生产配置下均可公开读取。

[训练回归测试](../../tests/training-quest.test.ts) 检查确定性与换组、题型结构、封闭答案可提交、数值范围、卡片可拼出答案、活动身份与顺序、空答案、来源与 SAMPLE 条件、题目依据、档案隔离、提示统计、纠错与模式切换；[基础闯关测试](../../tests/reading-quest.test.ts) 继续检查原有练习。

浏览器已验证：

- 数学《有几瓶牛奶·9加几》完整九关、答错与分步提示、拼算式、连续借书情境、小结和换组。
- 英语 `Look and see` 拼写与长单词重复字母、词义配对、拼写维修、介绍句排序；完整英文答案不在题干里显示。
- 语文《我不是最弱小的》完整九关、原文依据、字词卡片、推理、排序、情境迁移、多选漏选与小结。
- 三个训练页面在 320、768、1280 CSS 像素宽度无横向溢出，控制台无错误。测试使用独立的 `localhost:5174` 档案，不改变用户 `localhost:5173` 的教材选择。

上述结构、工程与交互检查不替代逐题教学效果评估。仍有同方法题和通用阅读题，尚未加入自适应难度、跨设备同步或口语评分。体验优化修正了分类题使用数量／单位提示的问题；没有宣称全部课程提示均已逐题人工审核。
