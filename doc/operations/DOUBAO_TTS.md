# 豆包语音：按需生成与声音切换

2026-09-07。面向本地项目维护者。已增加语音生成脚本、Vite 本机接口与两处声音切换；没有修改课程、练习判分、学习进度或掌握度。

## 页面使用

英语课文／课外阅读的「英语跟读角」和「听指令摆物」都有「朗读声音」选择框。每个新挂载的播放器默认浏览器语音，选择只在当前组件内存中保留，不跨刷新保存。切换本身不请求豆包；选择豆包后点击朗读、重听、上一句或下一句才请求音频。连续听读会自动为后续句子请求音频，选择连续模式前应确认费用。

浏览器语音不调用豆包；设备声音自身是否联网由设备提供方决定。豆包模式把当前英文文本发送给火山引擎，不发送学生档案、答案或录音；界面提示可能计费与家长确认。不提供口语评分，也不将合成音频标为教材官方原声。配置的音色不自动更换，英语发音与模型权限应在控制台试听确认。

切换声音、静音、改变语速／模式、切换文本、离开页面或隐藏页面会停止当前播放并忽略过期响应。暂停后继续会从本句开头重放。请求已经送到供应商后，停止播放器不能保证取消计费；本地服务允许该请求完成并保存缓存，减少再次调用。失败不会自动重试或自动切换供应商，用户可以手动重试或选择浏览器声音。

## 本地配置与启动

真实配置保存在项目根目录 `.env.tts.local`，其字段说明见 `.env.tts.example`。密钥禁止写入示例文件、前端、`VITE_` 变量或公开目录；本地文件被 Git 忽略。生成器每次读取该文件，无需把密钥复制到网页。

```sh
npm run dev
```

使用 `http://localhost:5173` 或实际终端输出的本机端口。无需额外启动后台进程，Vite 插件提供 `POST /api/tts/doubao`。接口仅接受回环地址、同源 Origin、JSON 请求及指定请求头；其他请求拒绝。没有 CORS 开放配置，不支持局域网手机直接调用。

**目前仅支持本地开发。** 静态生产构建和 `vite preview` 不提供这个接口，页面会提示使用浏览器语音。若要公网部署，必须另建鉴权、用户额度和限流齐备的服务端，不能直接暴露此开发接口。

## 独立生成脚本

先查看帮助（不读取密钥、不调用服务）：

```sh
npm run tts:generate -- --help
```

确认愿意产生合成费用后，可以生成一段文本：

```sh
npm run tts:generate -- --text "Hello! How are you?" --confirm-cost
```

也可以用 `--file` 替代 `--text`，传入 UTF-8 纯文本文件。每次最多 2000 字符；当前不自动遍历教材批量扣费。缺少 `--confirm-cost` 时命令拒绝运行。命令输出 MP3 缓存文件的绝对路径，不打印密钥或完整供应商错误正文。

## 实现与缓存边界

- `scripts/tts/volcengine.ts` 拥有配置读取、输入校验、火山请求、分片解析和本地缓存；请求采用用户控制台提供的 V3 HTTP 单向接口，密钥通过 `X-Api-Key` 发送，资源及音色使用本地配置。协议参考 [官方 API 列表](https://www.volcengine.com/docs/6561/2228192?lang=zh) 和 [字节跳动官方合成示例](https://github.com/bytedance/agentkit-samples/blob/main/skills/byted-text-to-speech/scripts/text_to_speech.py)。
- 解析 NDJSON／SSE 风格的 Base64 分片，要求成功结束标记和非空 MP3 头；异常、截断或空响应不入缓存。45 秒超时，响应最多 12 MiB。
- `.tts-cache/` 保存以文本、资源、音色、格式、采样率和实现版本计算的 SHA-256 文件名。缓存不含明文密钥，完成后原子写入；已有可识别 MP3 不重复合成。相同内容跨本机档案复用，不代表共享学习记录。
- 同一个服务实例合并相同文本的并发请求，最多 2 个并发新任务、每分钟 20 次新任务。此限制不是账单总额上限，不跨独立 CLI 进程共享；没有自动重试。缓存目前没有自动清理，维护者可按磁盘容量管理；删除后再次使用会重新生成并可能计费。
- 缓存目录和配置均被 Git 忽略，并由 Vite 文件拒绝规则保护。浏览器通过接口获得音频字节，不接收密钥、供应商响应正文或服务器文件路径。
- `useEnglishReadAloud.ts` 拥有播放器状态：浏览器模式沿用原实现；豆包模式请求本地接口后以 Blob URL 播放，停止时回收资源。0.7／0.85／1 倍速通过播放器保音高调整，不因切换速度重复生成。
