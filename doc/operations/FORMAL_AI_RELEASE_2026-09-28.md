# 正式 AI 计算专项接入验收

## 交付范围

正式知识点详情页、正式 Agent 学习建议页新增「AI 计算专项」，覆盖 25 个一年级上下册、二年级上册加减计算知识点。入口只在支持的知识点显示；语文、英语、几何等题型仍使用已审核题库。

真实模型由正式家庭 API 调用，不依赖开发路由或演示学生。专项记录保存在家长账号所属的 SQLite 会话中，按本机学习档案区分。结果标记为 `REAL_LLM` / `AUTO_VALIDATED`，不伪装为人工审核题目，不直接改变课程掌握度、奖励或正式错题本。

## 服务端边界

- `/api/pet/ai/status`：登录后读取服务开关。
- `GET /api/pet/ai/sessions`：按档案、教材、知识点恢复最近一组练习。
- `POST /api/pet/ai/sessions`：服务端目录确定知识点和运算规则，生成固定 3 题。
- `POST /api/pet/ai/sessions/:id/answers`：服务端判分并幂等保存；题目提交前不发送正确答案或解析。
- 复用 HttpOnly / SameSite 会话、生产 Secure Cookie、可信 Origin、请求标头及当前账号校验；请求大小上限 4 KiB。
- 出题只接受上下文编号及幂等请求编号，不能提交提示词、模型地址、密钥或教材文本。向模型发送的内容不含用户账号、档案身份、历史答案。
- 逐题校验数值范围、运算、进退位、固定操作数、整十条件、答案和重复题。模型失败或校验失败返回明确错误，不用 Mock 补齐。
- 出题最多等待 45 秒，不自动重试。每账号 10 次/滚动小时、30 次/滚动 24 小时，全服务 300 次/滚动 24 小时；失败尝试也占额度。单进程并发上限 2，每账号最多 1 个进行中请求。
- SQLite 保留幂等编号及配额；进程重启不会清空额度。长期遗留的 pending 记录会在 120 秒后标记失败。

## 实际模型与页面验收

使用生产前端构建、`NODE_ENV=production` 后端和独立测试数据库，通过浏览器操作完整流程。测试使用独立的本地 HTTP origin；公网 TLS 终止由部署的 Caddy 承担，Secure Cookie 属性另有接口测试覆盖。

1. 从正式数学地图进入「做个加法表 · 找加法规律」。
2. 注册隔离测试家长账号，通过页面发起真实生成。
3. 模型 `deepseek-v4-flash-0731` 返回 3 道题：`2＋3`、`4＋5`、`6＋4`。
4. 模型耗时 7,608 ms；输入 402 token、输出 561 token，总计 963 token。
5. 正确答案 5 判为正确；故意填写 8（4＋5）判为错误；答案 10 判为正确，最终 2/3。
6. 首题提交后刷新恢复到第 2 题；全部完成后再次刷新恢复完成状态，未重复调用模型。
7. 专项成绩保存在服务端；正式课程进度、宠物积分未被该专项直接修改。

模型与答案证据：`.data/llm-evaluations/formal-production-ui-2026-09-28.json`（不含凭据）。
