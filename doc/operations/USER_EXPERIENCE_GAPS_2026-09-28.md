# 知识岛：从学生与家长视角看功能缺口

日期：2026-09-28。基于当前正式构建的本地体验，不是上线环境审计。

## 体验范围

使用独立测试数据库和新账号，完成注册、地区/年级/教材配置，进入首页，完成《我是中国人》的两步课程，故意答错课后闯关第一题并查看提示，随后查看错题本、家长报告、成长与宠物、个人中心、家庭档案、设置与账号页。实际完成免费领养、用课程所得积分兑换苹果并喂养。

同时检查了页面、路由和相关存储逻辑。本次没有测完整个学期、没有完成整组闯关，也没有重新调用收费模型；有关缺口限定于上述体验及代码核对。体验使用测试数据，没有修改现有用户记录或业务代码。

## 判断

项目已有教材选择、地图、课程、练习、错题本、复习、学习报告、周计划、家庭档案、账号同步和宠物。下一阶段应优先让用户能确定起点、完成每天的任务、找回错误、获得帮助，以及管理账号。

## 建议补齐的模块

| 优先级 | 模块 | 实际用户问题与现状 | 最小可用范围 / 验收标准 |
| --- | --- | --- | --- |
| P0 | 账号找回与账号管理 | 注册页明确提示暂不支持自助找回密码；账号页有同步、备份和退出，没有修改密码、找回流程或登录设备管理。家长忘记密码后没有产品内恢复路径。 | 提供可验证的找回渠道、修改密码、查看并退出其他设备；补齐账号注销与数据处理入口。恢复完成后学习档案仍属于原账号。 |
| P0 | 家长模式与操作确认 | 家长报告和家庭档案可从孩子的个人中心直接进入，没有家长身份确认。已有多个孩子的档案，但不等于已有家长管理权限。 | 家长模式入口、家长验证、孩子端与管理端明确区分；切换孩子、恢复备份等管理操作有清晰身份和影响范围。家长能设置学习时段、时长和休息提醒。 |
| P0 | 题目纠错与问题反馈 | 课程和练习中找不到“题目有问题”“看不懂解析”“声音不能播放”的反馈入口；设置的帮助主要是静态说明。AI 出题已有功能，更需要可追踪的纠错渠道。 | 题目/课文/音频旁可提交问题，自动带上内容编号、版本和出错页面；提交后可查看处理状态。配套最小管理端接收、处理、修订和回告。 |
| P1 | 学习起点设置 | 初次设置只问地区、年级和教材，进入首页就推荐第一课；没有问学校学到哪个单元、孩子已经学过什么、目前想预习还是复习。已有 Agent 建议，但不能替代这些输入。 | 允许选择学校进度、学习目的及每日可用时间，提供可跳过的短诊断；用诊断建议起点，允许家长调整，并说明推荐原因。学校进度不直接等同于已经掌握。 |
| P1 | 统一的每日学习流程 | 首页有今日任务、周计划、各科地图及课外活动。本次新账号“今日任务”是 1 项，“周一目标”默认是 2 项，用户要自行理解两者关系。 | 让周计划真正生成可执行的今日清单；能选 10/15/20 分钟等学习量，将课程、练习、复习串起来；有暂停、续学和当天总结，完成结果回写同一个计划。 |
| P1 | 跨模块错题与复习中心 | 本次课后闯关答错一题后离开，错题本仍显示没有错题。源码显示闯关错误先保存在该组进度里，完成整组后才汇总活动记录，和正式教材错题是不同入口。 | 将教材练习、课后闯关及 AI 练习需要回顾的题统一展示，但保留来源和证据类型；中途离开也能找回错误。支持查看自己的答案、分步提示、再练与复习时间，不把活动参与自动算成教材掌握。 |
| P1 | 面向家长的行动报告 | 已有学习报告、时间/学科筛选和陪伴建议，不需要再建一个统计页。但家长仍要在报告、错题、计划之间切换。 | 汇总“本周进步、当前困难、下周建议”，每条建议能加入学习计划；支持按需查看或订阅周报。缺少证据时明确显示信息不足，不凭完成次数判断能力。 |
| P2 | 课内即时求助 | 当前示例错题反馈是“还差一点点”，展开后是固定提示；未看到针对“为什么错”“换个例子”的连续求助入口。AI 出题与讲清问题是两种需求。 | 从当前题目发起“再给一点提示 / 换个例子 / 读给我听”，按孩子年级组织解释，优先引导思考；无法解释或怀疑题目有误时能转反馈。 |

P0 表示开放给真实用户前优先补齐；P1 表示学习主流程；P2 可在主流程稳定后迭代。这些是产品优先级判断，不是法规合规结论。

## 已有功能的衔接问题，应先修而不必新建模块

1. **同步说明冲突。** 账号页说明学习记录自动同步；设置页“资料保存在哪里？”仍写换设备不会同步。用户无法判断数据是否安全保存。阅读/闯关中也仍有“保存在这台设备”等旧提示，应按真实保存状态统一表达。
2. **入口分散。** “今日”复用了首页；“今日 Agent 建议”在个人中心，今日任务和周计划又在首页。儿童需要的是一个清楚的“现在做什么”，不必理解 Agent 名称。
3. **角色与宠物的关系不明确。** 首次设置显示“选择知识团子”，实际只有默认角色；进入成长页仍需另行领养宠物。应说明二者关系，或合并首次伙伴设置。
4. **奖励概念较多。** 当前同时展示可用积分、累计学习积分、教材成长能量和宠物经验。基础计算及兑换能用，但孩子需要更简单的主界面，详细规则留给家长或展开查看。
5. **缺教材后的后续路径不足。** 总览已能显示三至六年级尚未接入，以及二年级下册的数学/英语缺失；还可提供申请教材、查看接入进度和适龄替代内容入口。三年级原创拓展已有，不应误称三年级完全没有内容。

## 推荐推进顺序

第一批：账号找回、家长管理、题目反馈，以及同步说明/入口命名等现有问题。

第二批：学校进度与学习起点 → 统一每日计划 → 跨模块错题复习。用一个完整场景验收：孩子设置学校进度，学一小段，答错并退出，第二天能直接继续并找到该题，家长看到明确的陪伴建议。

第三批：行动报告、学习提醒、课内即时求助和教材需求跟进。先不以增加商城、排行榜或新的独立群岛为主。
