# 统一登录注册与账号数据验收

## 交付内容

- 新增 `/login`、`/register`，支持密码确认、显示/隐藏密码、表单校验、错误提示、防止重复提交、登录后返回原页面。
- 正式页面与新手配置都要求登录。新账号配置地区、年级、教材和角色，已有账号先恢复云端记录再展示学习页面。开发实验室仅在开发路由开关允许时保留原入口。
- `/account` 提供同步状态、手动重试、退出、账号备份下载/恢复、冲突处理及旧数据绑定；首页顶部和“我的”页有入口。
- 宠物、家庭档案和 AI 专项移除重复的登录注册表单，使用同一账号会话。旧版独立档案备份继续保留。

## 数据范围与隔离

本机 localStorage、临时 sessionStorage 和宠物 IndexedDB 都按账号隔离。云端 `account_data` 表使用会话解析出的用户 ID 作为主键，客户端不能传入其他用户 ID 指定归属。

同步内容包括：所有孩子的学生资料、教材设置、课程与题组会话、掌握度及证据、学习历史、错题、复习、奖励、成长与成就、日计划与周计划、地图进度、互动活动、阅读闯关、思维训练、宠物故事、宠物背包及成长流水、家庭档案目录和偏好。测试逐项比对现有档案注册表，防止遗漏。

AI 专项已经直接保存到账号所属服务端记录中；账号快照保留原始学习档案 ID，跨设备恢复不会切断 AI 练习关联。密码、Cookie、模型密钥、临时 Agent 启动参数和恢复日志不进入账号快照。

旧浏览器记录需要显式勾选绑定或从账号页面操作，仅允许导入空账号。原始副本保留；同一浏览器的旧记录不会被第二个账号重复认领。已有云端记录不能被旧数据直接覆盖。

## 同步与失败处理

- 数据变化后约 1.2 秒自动提交；联网、窗口重新获得焦点、页面隐藏和 30 秒周期触发同步或检查更新。
- 登录与首次恢复需要网络；已打开页面的离线变更仍保存于当前账号本机缓存，恢复网络后重试。
- 上传使用版本号和内容摘要。相同内容重试幂等，多设备并发修改返回 409；不会自动合并或静默覆盖。
- 冲突选择前下载另一份记录作为备份；账号备份恢复支持预览，提交时再次检查云端版本，恢复前下载原记录。
- 恢复先写入新的存储空间与宠物数据库，再切换指针；写入未完成时保留旧空间。旧标签页无法继续写入已被替换的空间。
- 退出前先同步，待同步或冲突未处理时提示用户。其他标签页收到账号变化后重新校验会话；401 或账号不匹配立即回到登录入口。
- 当前采用完整账号快照与乐观并发控制；不支持双端自动合并。浏览器容量不足、请求超限、网络中断都会显示失败并保留可用本机副本。

## 后端和部署

- `GET /api/pet/account/data` 获取当前账号快照；`PUT` 需 `expectedRevision` 和严格校验的学习数据白名单。
- 复用 scrypt 密码散列、HttpOnly/SameSite Cookie、生产 Secure Cookie、Origin 和自定义请求头校验、当前账号匹配及请求限流。
- 请求体上限 8 MiB，快照最多 6 Mi 字符、4,000 项本机学习记录、100 份宠物档案；凭据请求限制为 4 KiB。
- SQLite 自动迁移到版本 4，新增 `account_data`，保留原账号、会话、家庭备份、宠物备份和 AI 会话表。
- 本地升级前备份：`.data/backups/pre-account-auth-2026-09-28T07-17-53.818Z.sqlite`。升级前后原表记录数量一致。
- Nginx 请求体上限相应调整为 8 MiB。公网部署仍须使用 HTTPS 与匹配的 `PET_ALLOWED_ORIGINS`。
- 暂未提供邮箱验证、密码修改和自助密码找回；登录注册页面已明确提示妥善保管凭据。
- 本次未发布公网；现有本地 `npm run dev:all` 已启动并使用新账号接口。
