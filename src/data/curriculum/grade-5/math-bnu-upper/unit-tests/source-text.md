# 北师大版五年级上册数学知识点整理

## ✅第一单元 小数的再认识和加减法

1. **小数的意义深化**
小数是十进分数，数位顺序表：整数部分、小数点、十分位、百分位、千分位；相邻计数单位进率为10。
2. **小数性质**：小数末尾添0或去0，大小不变，用于化简小数。
3. **小数大小比较**：先比较整数部分，整数部分相同依次比较十分位、百分位。
4. **小数加减法**：**小数点对齐（相同数位对齐）**，从低位算起；进退位规则同整数。
5. **小数加减混合运算**：运算顺序和整数一致；整数加法交换律、结合律对小数同样适用，可简便运算。

## ✅第二单元 三角形的再认识

1. **三角形定义**：三条线段首尾顺次围成的封闭平面图形。
2. **内角和**：三角形内角和=**180°**；直角三角形两个锐角之和=90°。
3. **三边关系**：**任意两边之和大于第三边，任意两边之差小于第三边**。
4. **三角形分类**

- 按角：锐角三角形、直角三角形、钝角三角形。
- 按边：不等边三角形、等腰三角形；等边三角形三边相等，三个角都是60°，属于特殊等腰三角形。

5. **三角形的高**：从顶点向对边作垂线，垂线段就是高；每个三角形有3条高。
6. **特性**：三角形具有稳定性。

## ✅综合实践：小小设计师

利用**轴对称、平移、旋转**，设计图案；能识别图形变换，用简单图形拼组、创作装饰图案。

## ✅第三单元 小数乘法

1. **小数乘整数**：求几个相同小数相加的简便运算。
2. **小数点移动规律**
小数点右移一位，扩大到原数10倍；右移两位，扩大100倍；
小数点左移一位，缩小到原数$\boldsymbol{\frac{1}{10}}$；左移两位，缩小到原数$\boldsymbol{\frac{1}{100}}$。
3. **积的小数位数**：两个乘数小数位数之和，就是积的小数位数。
4. **小数乘法竖式**：先按整数乘法计算，再数总小数位数，从积的右边起数位点小数点；末尾0可以化简去掉。
5. **积的变化规律**：一个乘数不变，另一个乘数扩大/缩小多少倍，积随之扩大/缩小相同倍数。
6. **小数混合运算**：整数运算律（交换律、结合律、分配律）适用于小数乘法，用于简便计算。

## ✅第四单元 用字母表示（一）

1. **用字母表示数**：字母可以代表数、数量关系、计算公式。

- 数字和字母相乘，省略乘号，数字写前面：$(a×4=4a)$；
- $(a×a)$写作$a^2$，读作a的平方；$2a$表示$(a+a)$。

2. **等式**：左右两边相等的式子；**方程**：含有未知数的等式。方程一定是等式，等式不一定是方程。
3. **等式的性质**
等式两边同时加、减同一个数，等式仍然成立；
等式两边同时乘或除以**不为0**的同一个数，等式仍然成立。
4. **解方程**：利用等式性质求未知数；求得的未知数的值叫方程的解。
5. **列方程解应用题**：找等量关系→设未知数→列方程→解方程→检验作答。

## ✅第五单元 多边形的面积

1. **面积单位**：平方厘米、平方分米、平方米；1平方米=100平方分米，1平方分米=100平方厘米。
2. 平行四边形面积：$\boldsymbol{(\boldsymbol{(\boldsymbol{S=})ah})}$（底×高）；推导：割补平移变成长方形。
3. 三角形面积：$\boldsymbol{(\boldsymbol{(\boldsymbol{S=})ah})÷2}$；两个完全相同三角形拼成平行四边形。
4. 梯形面积：$\boldsymbol{(\boldsymbol{(\boldsymbol{S=})(a+b)×h÷2})}$；两个完全相同梯形拼成平行四边形。
5. 等底等高：平行四边形面积相等；三角形面积相等；等底等高三角形面积是平行四边形的一半。
6. 组合图形面积：分割法、添补法，拆成基础图形计算再求和/差。

## ✅数学好玩：鸡兔同笼

用**列表法、假设法**解决鸡兔同笼类问题，理解假设思想，解决类似的两量混合应用题。

## ✅第六单元 图形的位置与运动（一）

1. **轴对称**：沿一条直线对折，两边完全重合；这条直线叫对称轴。能找对称轴、补全轴对称图形。
2. **平移**：图形沿直线移动，形状、大小不变，只改变位置；描述平移要说清**方向、格数**。
3. **旋转**：图形绕定点转动；描述旋转需要：中心点、方向（顺时针/逆时针）、旋转角度。

## ✅第七单元 倍数与因数

> 
> 研究范围：非0自然数

1. **倍数、因数**：$(a×b=c)$，a、b是c的因数，c是a、b的倍数。倍数与因数相互依存。
2. 2的倍数：个位0,2,4,6,8（偶数）；不是2的倍数是奇数。
3. 5的倍数：个位0或5。
4. 3的倍数：各个数位数字之和是3的倍数。
5. **质数（素数）**：只有1和它本身两个因数；**合数**：除1和本身还有别的因数。1既不是质数，也不是合数。
6. 100以内质数；最小质数2，最小合数4。

## ✅第八单元 可能性

1. 事件分三类：**一定发生、不可能发生、可能发生**。
2. 可能性有大小：数量越多，发生可能性越大；数量越少，可能性越小。
3. 判断游戏规则是否公平：看双方可能性是否相等。

## ✅综合实践：多少落叶能铺满

估算不规则图形面积，用数方格法；结合面积单位，估算落叶面积，感受估算策略。

## ✅总复习

整合本册：小数加减与小数乘法、三角形、用字母表示数与方程、多边形面积、图形变换、倍数因数、可能性。
